# Risco 0.1.0

Stable release. The GitHub Actions matrix compiled Linux, Windows x64 and
macOS arm64 and passed 12/12 automated tests per platform in run
[45734641224](https://github.com/lucioaraujo/risco/actions/runs/45734641224).
The Linux `.deb`, AppImage and user-local `.tar.gz` opened on Debian 12,
Ubuntu 24.04, Fedora and Arch in the same run. Windows and macOS passed their
automated builds and tests; their ZIPs have not been manually opened on
personal devices. The macOS app is Apple Silicon only, unsigned and not
notarized. Some advanced menus and messages remain in Portuguese; audio,
devices and interface behavior should be evaluated on personal computers.

## Português

Risco é um instrumento de composição generativa de Lúcio de Araújo, da família
RASGO. Desenhe, escreva ou use fórmulas sonoras para criar células, organize-as
em três pistas e automatize efeitos. Uma seed pode propor variações, faixas
completas e álbuns de projetos editáveis. O Risco exporta áudio WAV e permite
retomar a fila de exportação de álbum.

O pacote é para Linux x86-64 com ALSA e X11 ou XWayland. O render de álbum gera
WAV estéreo de 24 bits a 48 kHz. O formato de projeto desta versão é V76.

## English

Risco is a generative composition instrument by Lúcio de Araújo, part of the
RASGO family. Turn drawings, text and sound formulas into cells, arrange them
on three tracks and automate effects. A seed can propose variations, complete
tracks and albums of editable projects. Risco exports WAV audio and can resume
an album export queue.

This package is for x86-64 Linux with ALSA and X11 or XWayland. Album exports
are stereo 24-bit WAV at 48 kHz. This version saves projects in the V76 format.
