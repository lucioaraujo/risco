Risco 0.1.0 · evaluation

Install Risco

Choose a package for your system. Linux formats share an Ubuntu 22.04 build; files and checksums are listed in the evaluation release.

Linux x86_64

Ubuntu 22.04 or newer, Debian 12 or newer, Linux Mint 21 or newer, Fedora and Arch. The build uses glibc 2.35 as its baseline. The interface needs X11 or XWayland and audio uses ALSA. The Debian package installs its system dependencies.

Debian, Ubuntu and Mint · .deb

  1. Download the .deb package.
  2. Open it with your graphical installer, or run sudo apt install ./risco-0.1.0-linux-x86_64.deb from the download folder.
  3. Launch Risco from the applications menu. Remove it with sudo apt remove risco.

Other distributions · AppImage

  1. Download the AppImage.
  2. Allow it to run in the file properties or run chmod +x risco-0.1.0-linux-x86_64.AppImage.
  3. Open it with a double-click or run it from a terminal.

Install for your user · .tar.gz

  1. Download and extract the .tar.gz archive.
  2. From the extracted folder, run ./install.sh. Risco installs into ~/.local without administrator privileges.
  3. To remove the application files, run ./install.sh --remove from the same package folder.

Windows 10 or 11 · x64

  1. Download and extract the ZIP archive.
  2. Open Risco.exe. If Windows reports a missing MSVC DLL, install the Microsoft Visual C++ v14 Redistributable x64.

macOS · Apple Silicon

  1. Download and extract the ZIP archive, then open Risco.
  2. The app is unsigned and not notarized. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway.

This package is for Apple Silicon; Intel Macs are not included.

These are evaluation packages. Automated checks cover build, tests and startup on the listed systems; interface, fonts, audio and devices still need evaluation on personal computers. SHA256SUMS · source code.
