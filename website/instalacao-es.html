Risco 0.1.0 · evaluación

Instalar Risco

Elija el paquete de su sistema. Los formatos Linux comparten una compilación de Ubuntu 22.04; los archivos y las sumas están en la versión de evaluación.

Linux x86_64

Ubuntu 22.04 o posterior, Debian 12 o posterior, Linux Mint 21 o posterior, Fedora y Arch. La compilación toma glibc 2.35 como base. La interfaz necesita X11 o XWayland y el audio usa ALSA. El paquete Debian instala sus dependencias del sistema.

Debian, Ubuntu y Mint · .deb

  1. Descargue el paquete .deb.
  2. Ábralo con el instalador gráfico o ejecute sudo apt install ./risco-0.1.0-linux-x86_64.deb desde la carpeta de descargas.
  3. Abra Risco desde el menú de aplicaciones. Para desinstalar: sudo apt remove risco.

Otras distribuciones · AppImage

  1. Descargue el AppImage.
  2. Permita la ejecución en las propiedades del archivo o ejecute chmod +x risco-0.1.0-linux-x86_64.AppImage.
  3. Ábralo con doble clic o ejecútelo desde un terminal.

Instalar solo para su usuario · .tar.gz

  1. Descargue y extraiga el archivo .tar.gz.
  2. En la carpeta extraída, ejecute ./install.sh. Risco se instala en ~/.local, sin permisos de administrador.
  3. Para retirar los archivos de la aplicación, ejecute ./install.sh --remove desde la misma carpeta.

Windows 10 u 11 · x64

  1. Descargue y extraiga el archivo ZIP.
  2. Abra Risco.exe. Si Windows indica que falta una DLL de MSVC, instale el Microsoft Visual C++ v14 Redistributable x64.

macOS · Apple Silicon

  1. Descargue y extraiga el archivo ZIP y abra Risco.
  2. La aplicación no está firmada ni notarizada. Si macOS bloquea el primer inicio, vaya a Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente.

Este paquete es para Apple Silicon; no incluye Macs Intel.

Son paquetes de evaluación. Las comprobaciones automatizadas verifican compilación, pruebas e inicio en los sistemas indicados; la interfaz, las fuentes y el audio aún deben evaluarse en ordenadores personales. SHA256SUMS · código fuente.
