Risco 0.1.0 · avaliação

Instalar o Risco

Escolha o pacote do seu sistema. Os formatos Linux foram construídos a partir do mesmo build Ubuntu 22.04; os arquivos e checksums ficam na versão de avaliação.

Linux x86_64

Ubuntu 22.04 ou mais recente, Debian 12 ou mais recente, Linux Mint 21 ou mais recente, Fedora e Arch. O build usa glibc 2.35 como base. A interface precisa de X11 ou XWayland e o áudio usa ALSA. O pacote Debian instala as dependências do sistema.

Debian, Ubuntu e Mint · .deb

  1. Baixe o pacote .deb.
  2. Abra com o instalador gráfico ou rode sudo apt install ./risco-0.1.0-linux-x86_64.deb na pasta do download.
  3. Abra Risco no menu de aplicativos. Para remover: sudo apt remove risco.

Outras distribuições · AppImage

  1. Baixe o AppImage.
  2. Permita a execução nas propriedades do arquivo ou rode chmod +x risco-0.1.0-linux-x86_64.AppImage.
  3. Abra com duplo clique ou rode o arquivo no terminal.

Instalação no seu usuário · .tar.gz

  1. Baixe e extraia o arquivo .tar.gz.
  2. Na pasta extraída, rode ./install.sh. O Risco é instalado em ~/.local, sem pedir senha de administrador.
  3. Para remover os arquivos do aplicativo, rode ./install.sh --remove na mesma pasta do pacote.

Windows 10 ou 11 · x64

  1. Baixe e extraia o arquivo ZIP.
  2. Abra Risco.exe. Se o Windows informar que falta uma DLL MSVC, instale o Microsoft Visual C++ v14 Redistributable x64.

macOS · Apple Silicon

  1. Baixe e extraia o arquivo ZIP e abra o Risco.
  2. O aplicativo não está assinado nem notarizado. Se o macOS bloquear a primeira abertura, use Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.

Este pacote é para Apple Silicon; Macs Intel não estão incluídos.

Estes são pacotes de avaliação. A matriz automatizada confere build, testes e abertura nos sistemas listados; interface, fontes, áudio e dispositivos ainda precisam ser avaliados em computadores pessoais. SHA256SUMS · código-fonte.
