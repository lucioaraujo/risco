Risco 0.1.0 · évaluation

Installer Risco

Choisissez le paquet de votre système. Les formats Linux partagent un build Ubuntu 22.04 ; fichiers et sommes de contrôle figurent dans la version d’évaluation.

Linux x86_64

Ubuntu 22.04 ou plus récent, Debian 12 ou plus récent, Linux Mint 21 ou plus récent, Fedora et Arch. Le build prend glibc 2.35 comme base. L’interface utilise X11 ou XWayland et l’audio ALSA. Le paquet Debian installe ses dépendances système.

Debian, Ubuntu et Mint · .deb

  1. Téléchargez le paquet .deb.
  2. Ouvrez-le avec l’installateur graphique ou exécutez sudo apt install ./risco-0.1.0-linux-x86_64.deb dans le dossier téléchargé.
  3. Lancez Risco depuis le menu des applications. Pour le retirer : sudo apt remove risco.

Autres distributions · AppImage

  1. Téléchargez l’AppImage.
  2. Autorisez son exécution dans les propriétés du fichier ou exécutez chmod +x risco-0.1.0-linux-x86_64.AppImage.
  3. Ouvrez-le par double-clic ou depuis un terminal.

Installation pour votre compte · .tar.gz

  1. Téléchargez et extrayez l’archive .tar.gz.
  2. Dans le dossier extrait, exécutez ./install.sh. Risco s’installe dans ~/.local, sans privilèges administrateur.
  3. Pour retirer les fichiers de l’application, exécutez ./install.sh --remove depuis le même dossier.

Windows 10 ou 11 · x64

  1. Téléchargez et extrayez l’archive ZIP.
  2. Ouvrez Risco.exe. Si Windows signale une DLL MSVC manquante, installez le Microsoft Visual C++ v14 Redistributable x64.

macOS · Apple Silicon

  1. Téléchargez et extrayez l’archive ZIP, puis ouvrez Risco.
  2. L’application n’est ni signée ni notariée. Si macOS bloque le premier lancement, utilisez Réglages Système → Confidentialité et sécurité → Ouvrir quand même.

Ce paquet est destiné à Apple Silicon ; les Mac Intel ne sont pas inclus.

Ce sont des paquets d’évaluation. Les contrôles automatisés vérifient le build, les tests et le démarrage sur les systèmes indiqués ; interface, polices, audio et périphériques restent à évaluer sur des ordinateurs personnels. SHA256SUMS · code source.
