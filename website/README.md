# Risco website

Static editorial preview in Portuguese, English, French and Spanish. It has
an instrument introduction, a first-composition tutorial, platform status,
authorship and license links. The platform section links to the 0.1.0
evaluation archives and distinguishes successful CI builds/tests from manual
startup, interface and audio-device checks, which remain pending.

The pages and downloads are for evaluation. Archives and checksums are served
from `downloads/` on GitHub Pages. `robots.txt` blocks indexing while the
author reviews them and the later portal publication remains pending. Remove
that restriction only when the review and publication gates are complete.

The four pages share `style.css` and use the real control names so a reader can
follow the app. To publish this review version, use the repository's GitHub
Pages workflow. The general RASGO portal is a separate publication step.
