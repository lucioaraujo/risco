# Risco website

Static editorial preview in Portuguese, English, French and Spanish. It has
an instrument introduction, a first-composition tutorial, platform status,
authorship and license links. The platform section is deliberately factual:
Linux instructions exist; Windows and macOS builds remain unvalidated and no
installer is available yet.

This is a review preview, not a release. `robots.txt` blocks indexing until the
instrument's publication gates are complete. Remove that restriction only
alongside a reviewed release and complete cross-platform matrix.

The four pages share `style.css` and use the real control names so a reader can
follow the app. To publish this review version, use the repository's GitHub
Pages workflow. The general RASGO portal is a separate publication step.
