# Risco website

Static editorial preview in Portuguese, English, French and Spanish. It has
an instrument introduction, a first-composition tutorial, current evaluation
candidate downloads, step-by-step installation pages, authorship and license
links. Each language page links to the Linux `.deb`, AppImage and user-local
`.tar.gz`, plus the Windows and macOS ZIP archives of `v0.1.0-rc6`.

The pages are for evaluation. Packages and checksums are attached to the
GitHub pre-release; `robots.txt` blocks indexing while the author reviews the
pages and a later portal publication remains pending. Remove that restriction
only when the review and publication gates are complete.

The four homepages share `style.css` and show the same 1920×1006 capture
from the RC6 interface in English. The English tutorial explains how to
switch the main controls and help to English.

The repository's GitHub Pages workflow publishes the site. The general
RASGO portal uses its own publication process.
